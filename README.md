# Покупки клиента

Статический дашборд на русском языке. Откройте `dist/index.html` в браузере или запустите `python3 -m http.server 8765 --directory dist` из этой папки.

Данные поставляются с дашбордом, внешние библиотеки и интернет для локальной работы не нужны. В опубликованный набор не включены адреса и время доставки. Исходный Excel не изменяется.

## Обновление данных

Запустите `python3 scripts/prepare_data.py` (нужен openpyxl). Скрипт читает Excel из родительской папки, исключает отменённые заказы и сопоставляет изображения по нормализованному точному названию товара. Проверки: `node scripts/check.mjs`.

## Показатели

- Последний месяц выбранного окна показан в карточках; остальные блоки охватывают 24 месяца включительно.
- Число заказов — уникальные номера. При выборе категории — заказы с этой категорией.
- Сумма трат — фактическая сумма; общий итог включает услуги.
- Скидка взвешена по стоимости товаров без скидки, услуги исключены.
- В товарном графике штуки и рубли имеют отдельные линейные шкалы от нуля. Сортировка и поиск действуют на оба столбца одновременно.
- В подсказке цена за единицу взвешена по количеству за месяц. Месяцы без покупок показаны разрывами.
- Полнота первого и последнего месяцев исходника не подтверждена.

Браузерные инструменты WebMCP включаются только при наличии API; обычная работа дашборда от них не зависит.
